01 / Rules

A sequence you can see.

Build a renaming workflow from focused operations. Replace, insert, delete, or map text; clean and normalize names; control characters, capitalization, and extensions; generate ordered, padded, or random values; and use regular expressions, prepared input, or scripts for more specific logic.

  • Combine and reorder operations with drag and drop
  • Use file metadata in names and save useful rule presets
  • Preview each result before changes reach disk
Explore all rule guides ↗

02 / Rule Scope

Apply each rule where it belongs.

Rule Scope targets each operation to the files it should process. In a mixed folder, one rule can handle images, another can handle documents matching a filter, and a different rule can process the remaining files.

  • Assign selected files to a specific rule
  • Combine filters with scope to build precise file groups
  • Review every file included in a rule's scope

03 / Metadata

Read the file before you rename it.

Select a file to inspect its metadata beside the rename workflow. Lightning Renamer extracts technical and descriptive information across audio, image, and video formats, and lets supported fields become part of a new filename.

  • Audio tags and editable fields for supported formats
  • Photo EXIF details including camera, lens, date, and GPS
  • Video codec, dimensions, frame rate, tracks, and duration

04 / Filtering

Find the exact set.

Start broad, then narrow with confidence. Search, combine conditions, and keep the current filter visible while you work through the files that matter.

  • Quick text search for an immediate first pass
  • Current filters stay visible and easy to clear
  • AND / OR logic for layered conditions

05 / Layout

Choose the workspace that fits.

Switch the workspace between horizontal and vertical arrangements to match the display, file set, and task in front of you. The same tools remain available in either layout.

  • Horizontal layout for wide displays
  • Vertical layout when more height is useful
  • Switch directly from the workspace toolbar

06 / Security & Privacy

Your files stay on your Mac.

Lightning Renamer operates within the macOS App Sandbox. File reading, renaming, and writing happen locally on your device, and files and filenames are not uploaded.

  • Local processing for file operations
  • Access limited to locations you authorize
  • No file or filename uploads
